From a small town in Madhya Pradesh to systems handling 100k+ requests a day.

I'm a tech all-rounder — give me a problem, not a stack. APIs, web frontends, Flutter apps, AI pipelines, real-time systems, cloud deploys: I'll pick it up and ship it. My favourite parts are the hard, invisible ones: API gateways, event-driven pipelines, caching that shaves real milliseconds, and auth that doesn't leak.
